# Ashmita Pandey: Personal Website

Single-page static site (HTML/CSS, a little vanilla JS). No build step.

- `index.html`, `styles.css`, `favicon.svg`, images in `assets/` (WebP + JPG fallbacks)
- Deployed on Render as a static site via `render.yaml` (publish path `./`)
- Local preview: `python3 -m http.server` then open http://localhost:8000
