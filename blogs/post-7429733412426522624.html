Recently discovered git worktree at work, and it genuinely made my day easier.

Ashmita Pandey · Feb 18, 2026 · Engineering Practices · Git

Recently discovered git worktree at work, and it genuinely made my day easier. I was working on two branches in parallel, which normally comes with a lot of switching and context loss. Using worktree, I was able to keep both branches open side by side and make progress on each without disrupting my setup. It reduced a surprising amount of mental overhead and saved time. One of those small Git features that quietly improves your workflow once you start using it.
