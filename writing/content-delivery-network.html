What is a Content Delivery Network (CDN)?

Originally published Jul 10, 2025

  • System Design
  • Infrastructure
An on-site adaptation of Ashmita’s earlier article, not a verbatim republication.

A product image might be uploaded once and viewed a million times. Sending each visitor to the origin server repeats the same trip. A content delivery network can keep reusable copies closer to visitors and handle a large share of those requests at the edge.

Trace the difference between a hit and a miss

An edge server checks whether it has a usable response for the requested cache key. On a hit, it can respond without consulting the origin. On a miss, it fetches the response and, if caching is allowed, can keep it for a later visitor. That can improve response time and reduce origin traffic, particularly for images, scripts, and other assets requested repeatedly.

Decide how long old content is acceptable

A file with a content hash in its name can be cached for a long time because a new file gets a new URL. Product information used during checkout may need to be much fresher. Account-specific responses need extra care so private data cannot enter a shared cache. Choose cache headers and invalidation rules by content type, then monitor hit rate and origin load.
